## Warianty i ustawienia

Wspólny poziom RMS −24 dBFS, mierzony na pierwszych 12 sekundach. Wyrównanie jest zwykłą zmianą głośności po efekcie; bez limitera, kompresora, wzmacniacza i kolumny. RMS nie jest pomiarem głośności LUFS. Oryginalne różnice poziomu znajdziesz w katalogu `raw-gain` w ZIP. Tam Boost przekracza 0 dBFS: do odsłuchu w DAW zmniejsz poziom; zapis float zachowuje te szczyty bez obcinania.

## Nagranie i odtwarzalność

Czyste wejście pochodzi z GuitarML/GuitarLSTM: Fender Telecaster, przetwornik mostkowy, Tone i Volume gitary na maksimum. Autor projektu: Keith Bloemer. Użyto pierwszych 12 s pliku wejściowego `ts9_test1_in_FP32.wav`, nie nagrania po TS9. Repozytorium udostępnia go z licencją GPL-3.0; tekst licencji, oryginalny README i nieprzeskalowany fragment są w ZIP. Nie jest to nagranie użytkownika.

[Źródło nagrania](https://github.com/GuitarML/GuitarLSTM/blob/ee0983bb02af1e2db476466614d6421473beb01d/data/ts9_test1_in_FP32.wav) · [Manifest i pomiary](manifest.json) · [Weryfikacja plików](verification.json) · [Raport techniczny](../../docs/AUDIO_TESTS.md)

Każdy wariant dostaje dokładnie to samo wejście: stały gain 0.570950655, szczyt 0,25 V przy kalibracji 1 FS = 1 V. Nie znamy kalibracji napięciowej interfejsu oryginalnego nagrania — to jawnie wybrany poziom wejścia modelu. Fragment kończy się w 12 s; dalej wejście jest zerowe.

Render używa pełnego `MuffProcessor` z `Source/Plugin.cpp`, oversamplingu 4×, bloków 256 próbek, świeżego stanu i 100 ms ciszy wstępnej. Usunięto zgłaszane opóźnienie 6 próbek. To render tego samego kodu DSP co VST3, wykonywany przez narzędzie offline, nie zapis z FL Studio ani porównanie z fizycznym pedałem.

Po zbudowaniu celu `processor_tests` można odtworzyć komplet:

```sh
python tools/render_audio_demos.py /path/to/ts9_test1_in_FP32.wav \
  build-linux7/processor_tests_artefacts/Release/processor_tests /tmp/muff-audio
```

Wymagania: Python 3 + NumPy, ffmpeg z libmp3lame, skompilowany renderer JUCE; na Linux przy inicjalizacji JUCE dostępny DISPLAY (np. Xvfb). Zamiast pełnego źródła można podać `source/guitar-original-excerpt.wav` z ZIP: próbki użyte do DSP będą identyczne.
