# Experimental Windows development build

`JerzyMuffCollection-Win64-0.1.0.zip` contains the Win64 VST3 built from commit `16e667d`, complete project/JUCE sources and licence notices. The adjacent SHA-256 file verifies the archive.

Audio processing and processor-state tests passed under Wine. Full Windows pluginval timed out on the Editor test; native Windows and FL Studio compatibility remain unconfirmed. See ../docs/VALIDATION.md.

These binaries are provided here for a direct download while GitHub API access from the cloud environment is blocked. Native Windows/Linux CI builds are configured separately.
